# 音游成绩

这里是「音游模式」传上来的成绩，**一条一个 json**，按曲子放在子目录里：

    音游记录/<曲名>/<时间>-<随机数>.json
    音游记录/曲目索引.json                     # 总目录：哪些曲子有人传过

曲子是按**文件名**当身份的（国内曲库和 GitHub 曲库同名，两边能合起来比）。

* 程序只读最新的 30 个文件（文件名前面就是时间，倒着取）；
* 一条一个文件是为了不撞车：如果所有人往同一个大 json 里写，两个人同时上传
  必然有一个失败（contents 接口要 sha，改了就得重来）；
* 名字最多 12 个字，由用户自己填、自己点「上传到联网记录」才传；
* `曲目索引.json` 是**总目录**（谁传过哪首、传了几次、最高多少分），传成绩时顺手更新。
  程序靠它分清「这首歌还没人传过」和「网络不通」—— 列表拉不动时先读它，
  里面没有这首就说「还没人传过」，读不到它才提示检查网络。

**只在 Gitee**：GitHub 那边国内经常拉不到，成绩数据不放那儿（发版脚本也只把
`音游记录/` 推给 Gitee）。

想清空：把某个曲子的目录删掉就行（顺手把 `曲目索引.json` 里那一条也删掉），
程序拉不到就当这首歌还没人传过。
