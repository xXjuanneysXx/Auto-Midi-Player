# 错误报告

程序没接住的异常会自动打包成一份 json，传到这个目录里（文件名形如
`20261005-183012-A1B2C3.json`）。

## 里面有什么

- 程序版本、完全版 / 精简版、Python 版本、Windows 版本、是不是管理员
- 错误代码（`AP-XXXXXX`）、异常类型、调用栈（最多 60 行）
- 安装目录 / 调用栈里的路径**有没有中文**（一个布尔值）

## 没有什么

用户名、完整路径、歌名这些能定位到个人的东西。调用栈里的
`C:\Users\某某\...` 会被替换成 `<path>`，`<home>` 也是。

## 开关

程序「设置」里那个「出错自动上报」勾选框（默认开）。仓库根目录的
`error_report.json` 可以远程改开关 / 上报目录；用户自己关掉后以本机选择为准。
一次运行最多传 3 条，同一条错误只传一次。

> 这个目录是程序自动写的，别往里放曲子；曲库不会把这里的东西当歌解析
> （见 `library.is_meta_path`）。
